GUIDA BREVE - NUOVO UTENTE "broly"

Obiettivo
- Creare l'utente broly
- Dargli accesso in scrittura a /data tramite gruppo lab

Prerequisiti
- Eseguire i comandi con sudo
- ACL installate (pacchetto: acl)

1) Crea utente broly (se non esiste)
sudo adduser broly

2) Aggiungi broly al gruppo lab
sudo usermod -aG lab broly

3) Imposta /data per collaborazione col gruppo lab
sudo chgrp -R lab /data
sudo chmod -R g+rwX /data
sudo find /data -type d -exec chmod g+s {} \;
sudo setfacl -R -m g:lab:rwx /data
sudo setfacl -R -d -m g:lab:rwx /data

4) Applica i nuovi gruppi alla sessione di broly
- Fai logout/login come broly (obbligatorio)

5) Verifica rapida
id broly
getfacl /data | head -n 20

Test pratico (come broly)
touch /data/test_broly_write
ls -l /data/test_broly_write

Note
- Se "setfacl" non esiste: sudo apt install acl
- Evita chmod 777: meglio gruppo + ACL
