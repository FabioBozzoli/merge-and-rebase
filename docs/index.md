# merge-and-rebase

`merge-and-rebase` provides configuration-driven workflows for fine-tuning models, merging independently specialized checkpoints, and transporting task vectors across pretrained bases.

Start with [Getting Started](getting-started.md), then follow a [tutorial](tutorials/reproduce-vision8.md). Use the [configuration reference](configuration.md) when adapting an example to new tasks or checkpoints.

The repository README remains the short installation and navigation entry point for GitHub visitors.
